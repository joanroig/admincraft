# Developer documentation

This section is only for contributors, self-hosters compiling Admincraft, and
maintainers publishing their own builds. It is not required to install the
official app, connect a server, or use Google Drive sync.

| Goal | Page |
| --- | --- |
| Run or compile the Flutter project | [Build from source](building.md) |
| Enable Drive in a custom build | [Google Drive OAuth for custom builds](google-drive-oauth.md) |
| Change application icons and theme sprites | [Logo and brand assets](../logo/LOGO_DESIGN.md) |

For the server-side Docker bridge, use [Set up a server](../getting-started/index.md).
For normal app usage, use [Use Admincraft](../getting-started/install.md).
